# GenerateFromTextFile
## 概要

**GenerateFromTextFile**
は、テキストファイルに記載された複数行のプロンプトを読み込み、指定した解像度・枚数・モデル設定に基づいて画像を一括生成するためのノードです。\
Stable Diffusion（ComfyUI環境）で大量のプロンプトを処理する用途に適しています。

## 主な機能

-   テキストファイルの各行をプロンプトとして読み込み
-   複数解像度・生成枚数を指定可能
-   ランダムモードで行をランダム抽出（重複なし）
-   生成する 1画像ごとにランダムな seed を自動生成
-   自動画像保存

## 入力項目

  項目名                  説明
  ----------------------- -------------------------------------
  **file_path**           読み込むテキストファイルのパス
  **resolution_counts**   `"幅*高さ:枚数"` のカンマ区切り指定
  **random_mode**         ランダムに行を抽出するか
  **negative_prompt**     ネガティブプロンプト
  **model**               使用するモデル
  **clip**                CLIP エンコーダ
  **vae**                 デコーダ
  **steps**               サンプリングステップ数
  **cfg**                 CFG スケール
  **sampler_name**        使用するサンプラー
  **scheduler_name**      使用するスケジューラ
  **output_prefix**       出力ファイル名の接頭辞

## resolution_counts のフォーマット

    幅*高さ:枚数

例:

    448*448:50, 512*768:100

## 動作の流れ

1.  テキストファイル読み込み
2.  必要枚数の計算
3.  行の抽出（順番 or ランダム）
4.  解像度ごとの生成ループ
5.  CLIP → Latent 生成 → KSampler → VAE Decode
6.  画像を保存
7.  最後に生成した画像を返す

## 注意点

-   行数不足の場合は警告を出し、可能な範囲で停止
-   ランダムモードでは重複しない

## まとめ

大量プロンプトの自動画像生成に最適なノードです。
